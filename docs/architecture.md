# Архитектура системы логирования

## Сетевая структура классов

Система построена на основе интерфейса `ILogger`.

### Узлы сети
- **ILogger** — центр сетевой структуры (абстракция)
- **FileLogger** — запись в файл
- **DatabaseLogger** — запись в базу данных
- **RemoteLogger** — отправка на удалённый сервер
- **ConsoleLogger** — вывод в консоль

### Принципы
- **DIP** — зависимость от абстракции ILogger
- **Open/Closed** — новые логгеры добавляются без изменения Application
- **Слабая связность** — Application не знает о конкретных классах
